# 简物商城 PC 用户端原型

直接用浏览器打开 `index.html`，无需构建或启动后端。建议窗口宽度 1280px 以上。

## 体验路径

1. 首页 → 商品详情 → 加入购物袋；首次操作进入登录，使用虚构手机号或邮箱及至少 6 位演示密码。
2. 登录后重新点击购买 → 购物袋 → 确认订单 → 提交订单 → 模拟支付 → 查看订单。
3. 我的订单支持全部订单、待付款、待发货、待收货、已完成、已取消筛选。点击“加载各状态示例订单”体验确认收货、取消、再次购买。
4. 收货地址支持新增、编辑、默认、删除；个人中心支持昵称修改及演示修改密码。
5. 搜索不存在的商品可以查看空结果状态，帆布包用于查看缺货状态。

## 边界

- 仅用户端静态交互，不接入后端、真实认证、支付、物流或库存服务。
- 浏览器 localStorage 保存演示昵称、地址、购物袋和订单；密码不保存。请勿输入真实个人信息。清除站点数据可重置原型。
- 订单 15 分钟超时在页面打开或操作时计算，关闭页面后重开也会检查；不代表后端定时任务已实现。
- 商品为内置演示数据，图片为内联 SVG 示意图，无远程资源依赖。原型未包含后台发货、售后退款、优惠券、评价等后续能力。
- 标准版为唯一版本，两种颜色共享示例库存；真实 SKU 定价、库存、幂等和鉴权需后端实现。
- 未改动 Maven 模块和测试代码。
