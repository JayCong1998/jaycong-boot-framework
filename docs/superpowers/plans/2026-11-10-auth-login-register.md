# Auth 登录注册实施计划

用户已确认手机号或邮箱密码认证、Sa-Token 和本机 Redis 会话方案。MySQL 沿用当前配置，SQL 仅供手工执行。

- 添加受 BOM 管理的 Sa-Token Redis 适配器和 BCrypt 依赖。
- 为 sys_user 实现独立实体、Mapper、审计自动填充、逻辑删除及乐观锁插件，不修改公共 BaseEntity。
- 添加注册、登录、退出和当前用户接口，注册固定 user，不自动登录；邮箱转小写，手机号统一为中国大陆 11 位格式，兼容 +86/0086 前缀。
- 密码为 8–64 字符且 UTF-8 不超过 BCrypt 72 字节边界；账号登录失败统一提示，注册以数据库唯一索引处理并发重复。
- 登录成功后乐观锁更新最后登录时间，再签发 24 小时 Redis Token。当前用户每次查库验证有效性；发现禁用或删除即撤销该用户全部会话。
- 编译 package -DskipTests，并启动临时端口通过 HTTP 验证正常和失败路径、Redis 会话及重启后有效性。按 AGENTS.md 不编写或修改测试代码。
