# MyBatis 集成实施计划

**Goal:** 完成用户已确认的分页、基础实体、时间审计、CRUD 示例及数据库配置。

**Architecture:** Starter 提供可被业务 Bean 替换的默认分页拦截器和 MetaObjectHandler；Core 保持无框架依赖。Example 通过真实 Mapper 和 H2 验证集成。

**Tech Stack:** Java 21、Spring Boot 3.5.16、MyBatis-Plus 3.5.17。

**Spec:** 本次对话已确认的范围；不引入用户上下文、逻辑删除或租户功能。

## 实施

- [ ] Starter：新增 `model/BaseEntity.java`（Long 自增主键及 LocalDateTime 时间字段）、`pagination/MybatisPages.java`（toPage/toResult）、`handler/AuditMetaObjectHandler.java` 和 `autoconfigure/JaycongMybatisAutoConfiguration.java`，注册 AutoConfiguration.imports。先编写自动配置覆盖测试与真实 H2 分页、更新填充测试，执行 `mvn -B -ntp -pl jaycong-mybatis-spring-boot-starter -am test`，确认失败后实现并通过。
- [ ] Example：新增 product 下实体、Mapper、请求 DTO、Controller；新增默认 H2 和 mysql profile、非破坏性建表脚本。先写真实 HTTP CRUD、分页、无效参数和不存在记录测试，执行 `mvn -B -ntp -pl jaycong-example -am test`，确认 404 失败后实现。
- [ ] 文档与验证：新增 docs/mybatis.md，更新 README；执行 `mvn -B -ntp clean verify` 并检查可运行 JAR。

## 约定

分页由 1 开始，最大 1000，超出总页数返回空列表；排序在服务端固定。插入保留显式时间，更新刷新 updatedAt 并禁止改写 createdAt。业务自定义 MybatisPlusInterceptor 或 MetaObjectHandler 时默认 Bean 退让。MySQL profile 禁用自动建表，凭据由环境变量提供。

工作目录没有 Git 元数据，直接在当前目录实现，不创建分支或提交。
