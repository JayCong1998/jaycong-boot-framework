# 商城前端实施计划

目标：在 mall-web 中构建独立 Vue 3 前端，还原已确认的商城原型及登录注册页。

架构：Vue Router 管理首页和认证页面；Pinia 管理认证与购物车；services 封装 Result 与 Bearer Token；shadcn-vue 提供基础组件，业务组件按职责拆分。商品为本地示例数据，认证通过 Vite 代理访问现有网关。

- [x] 建立 Vite、TypeScript、Tailwind、shadcn-vue 工程。
- [x] 实现导航、分类、轮播、商品卡片、搜索和购物车抽屉，支持移动端。
- [x] 实现登录注册表单、后端认证、会话恢复及退出。
- [x] 执行类型检查、生产构建及页面手工检查，记录运行说明。
