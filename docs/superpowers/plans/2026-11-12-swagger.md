# Auth / User Swagger 接入计划

目标：按已确认的“各服务生成文档、网关统一查看”方案，为 Auth 和 User 接入 OpenAPI。

- [x] 在 common 聚合中增加 jaycong-common-swagger，BOM 管理 springdoc 2.8.17 和公共模块版本；根聚合通过 common 包含新模块。
- [x] 公共模块提供 MVC UI 依赖、可覆盖的 OpenAPI Bean，配置文档标题、版本、相对服务入口及 Bearer 安全方案，不自动要求全部接口登录。
- [x] Auth 和 User 引入公共模块，为公开 Controller、请求、响应添加中文说明；User 内部 Facade 不进入公开文档。
- [x] Gateway 使用 WebFlux UI，显式转发 /openapi/auth 和 /openapi/user，保留业务路由并配置统一文档选择菜单。
- [x] 执行定向 Maven package -DskipTests，在临时端口启动三个服务，验证直连文档、聚合配置、文档路由、Swagger UI 静态资源及业务路径；确认网关不含 MVC。
- [x] 补充 docs/swagger.md，记录接入、认证使用、生产关闭方式及实际验证结果。

边界：不修改测试代码，不修改用户已有未提交工作，不向 Nacos 发布配置，不修改数据库初始化数据，不停止现有应用。调试使用独立端口与关闭注册发现或静态实例配置，完成后停止本次启动的进程。
