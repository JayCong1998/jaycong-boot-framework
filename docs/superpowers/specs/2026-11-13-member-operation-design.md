# 会员操作流水

沿用本次对话已确认的操作审计设计，记录操作人、会员、时间、来源、动作、变更及结果。只读管理入口放在会员管理下，现有会员列表保持 /members 地址。

本期接入现有管理员昵称修改、启用/禁用及撤销会话重试。当前没有会员本人修改接口，不新增无关业务入口；记录模型区分 ADMIN、MEMBER 身份及 ADMIN_WEB、MEMBER_WEB 来源，后续本人入口应从服务端会话获取身份后复用记录能力。

独立 MySQL 表保存审计流水，不记录请求原文、密码、Token、联系方式或底层异常。开始操作前提交 PROCESSING 记录；资料或状态数据库变更与流水阶段结果在同一事务提交。Redis 清理在事务外执行，禁用后清理失败为 PARTIAL，启用前清理失败为 FAILED。PROCESSING 表示处理中或进程中断后结果待核实，不伪称失败。日志持久化异常不吞掉。

仅正常管理员可分页、按会员/操作人 ID、动作、身份、结果及时间筛选并查询详情。无修改、删除接口。SQL 手工执行，不自动建表，不修改测试代码。存量操作不能回填。
