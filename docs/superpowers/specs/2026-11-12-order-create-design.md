# 单商品下单

用户已确认：一次只能购买一个商品。POST /orders 接收 goodsId 和可选 remark，用户身份取自 Auth 的 jaycong-auth Sa-Token 会话。订单服务通过 HTTP 获取商品服务的上架商品详情，保存商品快照和整数分价格。订单初始为待支付，默认 30 分钟过期；不处理支付、库存、交付或自动关单。每次成功调用创建独立订单，不承诺请求幂等。

订单继承公共 BaseEntity，使用应用生成主键、审计填充、逻辑删除和乐观锁。商品不可购买返回 404，下游不可用返回 503，未登录返回 401，参数非法返回 400。远程调用放在数据库写事务前，避免持有数据库事务等待网络。

复用现有业务聚合，补充订单启动配置、手工建表 SQL、网关路由和文档。遵守项目约定，不编写或修改测试代码；使用 Maven package -DskipTests 和条件允许的手工 HTTP 验证。
